Step 3b — Install in WordPress
  1. Log in to your WordPress admin dashboard
  2. Go to Plugins → Add New → Upload Plugin
  3. Click Choose File, select the zip you just downloaded, then click Install Now
  4. Click Activate Plugin
Step 3c — Add your API key
  1. In WordPress go to WooCommerce → PhiXtra AI → Settings
  2. Copy your API key from the API Keys page
  3. Paste it into the API Key field and click Save Settings
